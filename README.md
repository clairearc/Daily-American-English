# Daily American English

A mobile-friendly daily English practice site for realistic contemporary American English.

## Structure

- `index.html` — app shell
- `styles.css` — responsive styling
- `app.js` — lesson loading, search, navigation, favorites
- `lessons/index.json` — lesson manifest
- `lessons/YYYY-MM-DD.json` — one lesson per day

## Publish with GitHub Pages

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site will be available at:

`https://clairearc.github.io/Daily-American-English/`
