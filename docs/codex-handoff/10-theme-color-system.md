# 方案 C 多色系交融系统与日夜间模式 · 2026-09-13

## 背景与设计目标

在**不改动现有 DOM 骨架、不修改课程文案与 JSON 数据**的前提下，升级全站视觉质感：
1. **多色系高雅交融**：摒弃单一单调色系，在一个方案中融合 3 种低饱和矿物色系，高雅淡雅、层次分明、不杂乱。
2. **日夜间双模式**：支持 ☀️ 日间淡雅 与 🌙 夜间护眼 无缝切换，支持持久化记忆与系统偏好自动同步。
3. **保留经典排版**：大标题沿用经典 `Georgia` 衬线体，正文与释义沿用现代清晰的 `Inter`。
4. **SVG 图标与微动效**：发音按钮升级为矢量 SVG 扬声器，播放中激活珊瑚红呼吸扩散光圈。
5. **导航活跃点睛（罗盘红针）**：侧边栏与右侧浮动目录在当前激活项均配备珊瑚暖红指示条（`border-left: 3.5px solid var(--coral)`），精准指引阅读位置。

## 核心色彩系统与语义分配 (Scheme C)

遵循 **60-25-15** 语义分配原则：

| 色系角色 | 语义作用域 | ☀️ 日间色值 | 🌙 夜间色值 | CSS 变量 |
| :--- | :--- | :--- | :--- | :--- |
| **色系 1 · 核心骨架 (60%)** | 核心词汇、大标题、侧边栏背景、主卡片描边 | `#23547F`（海港暮蓝） | `#5F9FD4`（晴空透蓝） | `--accent` / `--accent-soft` |
| **色系 2 · 交互与点睛 (25%)** | 播放中高亮、当前激活目录指示条、右侧浮动目录跟随、回顶箭头 | `#C9503E`（珊瑚暖红） | `#ED7463`（暮色微光珊瑚） | `--coral` / `--coral-soft` |
| **色系 3 · 辅助辨析 (15%)** | 学习目标卡片、易混词义辨析标题、微胶囊标签 | `#876E2A`（雅致橄榄金） | `#D6B254`（柔和月光金） | `--gold` / `--gold-soft` |

## 关键交互与视觉规范

1. **音频发音按钮（降噪与聚焦）**：
   - **默认闲置态**：采用低饱和 Slate 灰与次级面板色（`var(--paper-2)` + `var(--muted)`），在包含 40+ 单词的密集列表中保持视觉整洁静谧，不抢占阅读视线。
   - **悬停态**：呈现柔和海港暮蓝微反馈（`var(--accent-soft)` + `var(--accent)`）。
   - **播放激活态（`.playing`）**：点亮珊瑚暖红（`var(--coral)`）并伴随 `pulse-coral` 轻柔呼吸微光波纹。

2. **左侧课程层级目录（`.part-link`）**：
   - 当前正在学习的 Part 具有 `border-left: 3.5px solid var(--coral)` 珊瑚红竖向指示条与 `var(--accent-soft)` 底色。

3. **右侧六模块浮动目录（`.lesson-directory`）**：
   - 随页面滚动实时跟随，当前视口模块链接（`a[aria-current="location"]`）亮起 `border-left: 3.5px solid var(--coral)`，英文标题为 `var(--coral)`，背景转为 `var(--coral-soft)`。
   - 目录标头采用全大写珊瑚红小标头。

4. **右下角快捷导航（`.page-edge-nav`）**：
   - 上下箭头采用 `color: var(--coral)`，悬停带有微升浮动动效。

## 实现细节

1. **样式层 (`styles.css` / `site-v2.css` / `lesson-teaching.css`)**：
   - 全局变量在 `:root` 与 `[data-theme="dark"]` 中统一分发；
   - 消除旧文件中的硬编码色值，统一由 CSS Token 控制。
2. **结构层 (`index.html`)**：
   - `<head>` 注入微型防闪烁初始化脚本，读取 `localStorage.getItem('dae-theme')`；
   - 顶部工具栏 `.toolbar` 挂载 `#themeToggle` 明暗切换按键；
   - 引入版本号参数 `?v=20260913-coral2` 防浏览器旧缓存。
3. **逻辑层 (`app.js`)**：
   - 点击 `#themeToggle` 切换 `data-theme` 属性并同步写入 `localStorage`；
   - 自动同步移动端浏览器顶栏 `meta[name="theme-color"]`。
