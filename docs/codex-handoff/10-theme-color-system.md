# 方案 C 多色系交融系统与日夜间模式 · 2026-09-12

## 背景与设计目标

在**不改动现有 DOM 骨架、不修改课程文案与 JSON 数据**的前提下，升级全站视觉质感：
1. **多色系高雅交融**：摒弃单一单调色系，在一个方案中融合 3 种低饱和矿物色系，高雅淡雅、层次分明、不杂乱。
2. **日夜间双模式**：支持 ☀️ 日间淡雅 与 🌙 夜间护眼 无缝切换，支持持久化记忆与系统偏好自动同步。
3. **保留经典排版**：大标题沿用经典 `Georgia` 衬线体，正文与释义沿用现代清晰的 `Inter`。
4. **SVG 图标与微动效**：升级发音按钮为矢量 SVG 扬声器，播放中增加轻柔珊瑚红呼吸扩散光圈。

## 实现细节

1. **样式层 (`styles.css` / `site-v2.css` / `lesson-teaching.css`)**：
   - 全局变量在 `:root` 与 `[data-theme="dark"]` 中统一分发；
   - 媒体查询 `@media (prefers-color-scheme: dark)` 支持免配置默认暗黑；
   - 消除旧文件中的硬编码色值，统一由 CSS Token 控制。
2. **结构层 (`index.html`)**：
   - `<head>` 注入微型防闪烁初始化脚本，读取 `localStorage.getItem('dae-theme')`；
   - 顶部工具栏 `.toolbar` 挂载 `#themeToggle` 明暗切换按键。
3. **逻辑层 (`app.js`)**：
   - 点击 `#themeToggle` 切换 `data-theme` 属性并同步写入 `localStorage`；
   - 自动同步移动端浏览器顶栏 `meta[name="theme-color"]`。
